# 🎬 Midea Pro - Ultimate Media Downloader

![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%7C%2011-0078D6?style=for-the-badge&logo=windows&logoColor=white)
![Architecture](https://img.shields.io/badge/Architecture-64--bit-orange?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Standalone%20Executable-success?style=for-the-badge)

**Midea Pro** is a high-speed, modern standalone desktop application designed for Windows. Powered by `yt-dlp` and `FFmpeg`, it allows you to seamlessly download high-quality videos and audio from your favorite social media platforms—**no Python setup required**.

---

## 🌐 Supported Platforms

Download media effortlessly from major platforms:
* 🔴 **YouTube** (Videos, Shorts, Audio, Playlists)
* 🎵 **TikTok** (HD Videos without watermark)
* 🔵 **Facebook** (Public Videos, Reels)
* 📸 **Instagram** (Reels, Posts, IGTV)

---

## ✨ Key Features

* ⚡ **Ultra-Fast Downloads:** Uses the high-performance `yt-dlp` core to maximize your download speed.
* 🎥 **Multi-Resolution Options:** Choose quality from **360p, 480p, 720p, 1080p, 2K, up to 4K (Ultra HD)**.
* 🎵 **Audio Extraction:** Convert videos directly to high-quality **MP3** or **WAV** audio files.
* 🎨 **Modern Dark UI:** Clean, responsive, and eye-friendly Dark Mode user interface built with CustomTkinter.
* 📁 **Built-in FFmpeg:** Full media conversion tools integrated directly inside the executable—no extra installations needed.
* 📜 **Download History:** Track and manage your previously downloaded files easily.

---

## 💻 System Requirements

* **Operating System:** Windows 10 / Windows 11 (64-bit)
* **RAM:** 2 GB Minimum (4 GB Recommended)
* **Internet Connection:** Active broadband connection
* **Python Installation:** **NOT Required** (Fully standalone `.exe`)

---

## 🚀 How to Use

1. Download **`MideaPro.exe`** from the latest **Releases** section.
2. Double-click **`MideaPro.exe`** to run the app.
3. Paste any supported media link (YouTube, TikTok, Facebook, or Instagram).
4. Select your desired format/quality and click **Download**.

---

## 🛡️ Security & Anti-Virus Notice

* **Safe & Secure:** Midea Pro is compiled using C-binary extensions (`.pyd`) and PyInstaller for maximum performance and code safety. No personal data is ever collected.
* **SmartScreen / False Positive Note:** Windows Defender or third-party antivirus software may flag the app as *"Unknown Publisher"* because it is an unsigned executable. If this happens, click **More info** $\rightarrow$ **Run anyway** to launch the app.
