**Media Pro v1.2.0** is a modern, high-speed standalone desktop application built for Windows. Powered by `yt-dlp` and `FFmpeg`, it enables seamless video and audio extraction from a wide array of platforms with advanced batch features and a refined Windows 11 Fluent UI.

---

## 🌟 Key Features

* 🔗 **Universal Media Downloader:** Effortlessly download media simply by pasting links.
* 🌐 **Multi-Platform Support:** High-speed downloads from **YouTube, TikTok, Facebook, Instagram, Pinterest, Adult (18+) Sites**, and many more.
* 🎥 **Flexible Video Formats:** Video downloads in **MP4** format ranging from **144p to 2160p (4K)** as well as **Best Quality** auto-selection.
* 🎵 **Custom Audio Extraction:** Convert media into high-fidelity **MP3** files with adjustable bitrates from **128 kbps to 320 kbps**.
* ⚡ **Batch & Playlist Downloader:** Download entire playlists efficiently using multi-threaded execution with custom item selection.
* 🚀 **Speed Optimization Modes:** Switch between **Standard**, **Fast**, and **Extreme** speed profiles.
* 📁 **Downloads Manager & History:** Search through completed downloads, open destination folders, copy video URLs, and view dynamic thumbnail previews.
* 🎨 **Theme Customization:** Native support for **System**, **Light**, and **Dark/Night** modes.

## 📥 Installation & Setup

1. Navigate to the **[Releases](../../releases)** section of this repository.
2. Download the latest release package: `MideaPro-v1.2.0-Setup.zip`.
3. Extract (unzip) the contents of the downloaded `.zip` file.
4. Run `MideaPro-Setup.exe` and follow the on-screen installation wizard.

## 💻 System Requirements

* **Operating System:** Windows 10 / Windows 11 (64-bit)
* **Processor:** Intel 4th Gen / AMD FX or newer *(AVX2 CPU Instruction Set required)*
* **RAM:** 2 GB Minimum (4 GB Recommended)
* **Python Installation:** **NOT Required** (Fully standalone executable)
