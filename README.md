## 🌟 Features Overview

### 💻 Windows Features
* 🎬 **Video Editor Native Support:** Downloads pre-encoded H.264 (`avc1`) videos, preventing `av01` errors in Adobe Premiere Pro, CapCut, and DaVinci Resolve.
* 🎵 **Custom Bitrate Audio:** High-fidelity MP3 extraction (128 kbps to 320 kbps).
* ⚡ **Batch & Playlist Downloader:** Multi-threaded parallel downloading for full playlists.
* 🎨 **Fluent UI & Performance:** Native Light/Dark modes with Standard, Fast, and Extreme speed profiles.

### 📱 Android Features
* ⚡ **Fast Mobile Downloads:** Paste links to immediately save media to your phone storage.
* 🌐 **Multi-Platform Support:** Works with YouTube, TikTok, Facebook, Instagram, and more.
* 📦 **Optimized Footprint:** Split APK builds to ensure lightweight storage usage on mobile devices.

## 💻 System Requirements

### 💻 Windows Desktop
* **Operating System:** Windows 10 / Windows 11 (64-bit)
* **Processor:** Intel 4th Gen (Haswell) / AMD FX Series or newer *(AVX2 CPU instruction support required)*
* **RAM:** 2 GB Minimum (4 GB Recommended)
* **Storage:** 200 MB Free Space
* **Python Environment:** **NOT Required** (Fully standalone installer)

### 📱 Android Mobile
* **Operating System:** Android 7.0 (Nougat) or higher
* **Architecture:** `arm64-v8a` (64-bit) or `armeabi-v7a` (32-bit)
* **Storage:** 100 MB Free Space
